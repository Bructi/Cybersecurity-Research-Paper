### Diagram Inventory

#### 1. `diagram_a_attack_lifecycle.svg` / `.png`
- **Title:** Diagram A: AI-Enhanced Cyber Attack Lifecycle
- **Description:** Illustrates the machine-speed adversarial progression across seven classic cyber kill-chain phases:
  1. Automated Reconnaissance (OSINT ingestion, network topology inference)
  2. Weaponization (Polymorphic payload generation, obfuscated scripts)
  3. Social Engineering (Hyper-personalized LLM spearphishing, deepfake voice/video)
  4. Exploitation (Sub-15 minute automated PoC synthesis from CVEs)
  5. Persistence (Adaptive Living-off-the-Land, dynamic C2 jitter)
  6. Data Exfiltration (Automated document classification, compressed 72-minute exfiltration)
  7. Impact (Automated ransom negotiation, AI asset exfiltration)
- **Primary Source:** ENISA Frontier AI Cybersecurity Assessment (July 2026), CrowdStrike 2025 Global Threat Report, MITRE ATT&CK v18.

#### 2. `diagram_b_defense_lifecycle.svg` / `.png`
- **Title:** Diagram B: AI-Enhanced Cyber Defense Lifecycle
- **Description:** Illustrates continuous machine-speed defensive telemetry processing, behavioral detection, automated mitigation, and feedback loops:
  1. Multi-cloud log normalization and graph telemetry ingestion
  2. Unsupervised anomaly detection (Autoencoders, Isolation Forests)
  3. Graph Neural Network (GNN) lateral movement classification
  4. Automated IoC synthesis and threat intelligence fusion
  5. Machine-speed mitigation (Zero-trust quarantine, token revocation)
  6. Automated patch synthesis and disaster recovery rollback
  7. Continuous model retraining and adversarial fine-tuning
- **Primary Source:** NIST Cybersecurity Framework Profile for AI (NIST IR 8596), DARPA AIxCC (2025).

#### 3. `diagram_c_threat_taxonomy.svg` / `.png`
- **Title:** Diagram C: AI Cybersecurity Threat Taxonomy
- **Description:** Structured 3-column taxonomic classification:
  - **Column 1: Generative AI Attack Risks:** Phishing lures, multi-modal deepfakes, malware synthesis, automated reconnaissance, 15-min exploit generation.
  - **Column 2: AI Model & Data Risks:** Direct/Indirect prompt injection, training/model poisoning, adversarial perturbation (GCG/PGD), model extraction/distillation, membership inference.
  - **Column 3: Infrastructure & Agentic Risks:** Excessive agentic autonomy, AI supply chain tampering, vector database/RAG poisoning, shadow AI API key leakage, autonomous multi-agent swarms.
- **Primary Source:** MITRE ATLAS (v2026.05), NIST AI 100-2e2025, OWASP Top 10 for LLMs.
